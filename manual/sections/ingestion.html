Ingestion

Upload: multipart POST to /api/upload. Files land in the uploads/ directory. The server then runs a local ClamAV scan when clamscan is available, and local OCR / PDF text extraction (Tesseract.js + pdf-parse). Results are stored on the upload row; see docs/LOCAL_SCAN_OCR.md.

You may attach an optional patientId after creating a patient.

Manual entry: POST /api/patients/ingest accepts a JSON body with patient, labs, observations, and conditions. Labs are stored as Observations with category laboratory.

API: the same ingest endpoint can be used by external clients; OpenAPI can be added under packages/contracts in a future iteration.
