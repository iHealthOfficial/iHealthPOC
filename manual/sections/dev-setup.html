Developer setup

  1. From the repo root: npm install.
  2. Apply DB schema: npm run db:migrate from the repo root (do not run bare prisma—it is not installed globally).
  3. Start API + built UI on one port: npm run serve from the repo root.
  4. Open http://localhost:4000.

Optional: for hot-reload while editing React only, run npm run dev --workspace=@ihealth/web and use port 5173.

GitLab CI runs install, lint, and build on push. Edit any file under manual/sections/, commit, and push—the Manual page will show your changes after the API reloads (or redeploys).
